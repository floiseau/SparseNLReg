# Sparse NonLinear Regression (SparseNLReg)

A program for performing polynomial sparse regression using non-linear features, designed for symbolic regression.

## Installation

Clone the repository and install the package via pip:

    git clone git@github.com:floiseau/sparsenlreg.git
    cd SparseNLReg/
    pip install .

## Usage

Run the program using a configuration file:

    sparsenlreg config.toml

The resulting models are printed directly to the terminal, and additional plots are generated as SVG files.

## Examples

Example configurations and usage are provided in the `examples/` subdirectory.
